# Codex 定时任务维护

仅在 Mac mini 执行。凭据、运行数据和原任务记忆不入 Git，不输出认证信息。迁移验证使用模拟数据、账号/模型只读预检和只读看板，不主动发起业务模型、通知、PR 或邮件标记。保留周期、统计窗口、项目、原会话、记忆及去重凭据。通知仅走 notify.py 和统一 webhook-delivery；不绕过发送账本。

- SigNoz 的 EOF、超时、连接中断和 HTTP 429/500/502/503/504 在同一只读查询和时间窗口内等待 10、30、60 秒，最多重试 3 次；证书校验、权限及不存在等永久错误不做无效重试。只有截断、明确的查询资源限制或 count/extract 不匹配才拆窗，网络错误禁止递归拆窗。异常必须保留脱敏分类、底层类型、尝试次数、窗口和适用的证书校验信息，写入状态及看板摘要；不得记录 API key、SQL、响应体或任意异常原文。采集失败不调用模型、不发送报告、不冒充零数据。

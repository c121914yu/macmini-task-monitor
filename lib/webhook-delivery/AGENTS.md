# Webhook 统一传输

- 所有 Mac mini 自动任务调用本目录 helper：Python send()，Node postWebhook()。
- 仅在明确收到 HTTP 429 或飞书 11232/11233/11247 限流拒绝后，等待固定 60 秒重试，最多重试 3 次，总计最多 4 次请求；不重新采集数据或调用模型。
- 网络超时、响应损坏或发送结果未知时不自动重发；发送意图、结果与业务账本保持可核查。同一消息限流重试耗尽后不可被下一次自动补偿重置。
- 凭据和 payload 走进程内或标准输入，不打印、不放命令行、不纳入源码仓库；传输记录只保存状态、次数、时间和 endpoint 哈希。
- 测试模拟 HTTP 和 sleep，不发真实测试消息。
